# Karriera

AI job-market prep app for students (302-CSE Mobile App Development, UMIB).

CV review · job & internship listings from Kosovo portals · "Am I a fit for this job?" · AI interview with a 3D avatar (camera + voice, Albanian / English / German) · learning links.

## Stack

React Native + Expo (SDK 57, TypeScript, expo-router) · Supabase (Auth, Postgres + RLS, Storage, Edge Functions) · AI through Edge Functions only.

## Run

```bash
npm install
npx expo start
```

Open with Expo Go (same WiFi), or `npx expo start --tunnel` on networks that block LAN.
